Pro edition of Edminboost Admin Notice Manager — multisite network policy, email digest, webhooks, migration/import, white label, and advanced admin bar placement.

== Description ==

Install the Pro build for the full feature set described on the pricing page. Built from the same monorepo core as the Free plugin with Pro edition constants enabled.

== Installation ==

1. Upload and activate the Pro plugin folder (or replace the Free plugin if you are upgrading on the same site — backup settings first).
2. Configure features under **Notice Manager** in wp-admin.
